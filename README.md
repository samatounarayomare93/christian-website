## ✨ المميزات / Features

### 🙏 الميزات الروحية / Spiritual Features
- **📿 كتاب صلوات شامل** - مجموعة كاملة من الصلوات المسيحية
- **🕯️ شموع افتراضية** - أشعل شمعة لنيتك الخاصة
- **🎵 صوتيات روحية** - موسيقى وترانيم للتأمل
- **📅 جدول صلوات يومي** - تذكيرات للصلوات اليومية
- **🏆 نظام الشارات** - تتبع رحلتك الروحية

### 💻 الميزات التقنية / Technical Features
- **📱 PWA Support** - يعمل كتطبيق على الموبايل
- **🌐 Offline Mode** - يعمل بدون إنترنت
- **🌍 Bilingual** - دعم العربية والإنجليزية
- **♿ Accessible** - متوافق مع معايير الوصول
- **⚡ Fast** - أداء عالي وسرعة تحميل

## 🚀 البدء السريع / Quick Start

### المتطلبات / Requirements
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت (للتحميل الأول فقط)

### التثبيت / Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/soul-guidance.git

# Navigate to project
cd soul-guidance

# Open in browser
# Just open index.html in your browser!
```

### التطوير / Development

```bash
# Install dependencies (optional)
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
