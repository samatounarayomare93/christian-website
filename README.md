# Soul Guidance - إرشاد الروح
## Ultimate Digital Sanctuary v1.0

A "Superintelligence-Grade" Progressive Web App (PWA) designed for spiritual continuity, built with vanilla technologies for maximum performance and longevity.

### ✨ Key Features
- **Virtual Shrine**: Light virtual candles with real-time flame animation (`CandleManager`).
- **Liturgical Audio**: Ambient Gregorian chants with cross-fading controls (`AudioManager`).
- **AI Spiritual Advisor**: "Saint Oracle" provides mood-based scripture guidance.
- **Prayer Wall**: Infinite scrolling feed of community intentions (`PrayerWallManager`).
- **Offline Resilience**: Fully functional offline via Service Worker + "Emergency Prayer Kit".
- **Gamification**: Earn "Virtue Badges" and track spiritual streaks.
- **Perpetual Adoration**: Live stream placeholder for 24/7 devotion.
- **Divine Voice**: Control the app with voice commands like "Light Candle" or "Pray" (`VoiceManager`).
- **Digital Rosary**: Interactive prayer bead visualizer (`RosaryManager`).
- **Chronos**: Interface adapts to Dawn, Day, Dusk, and Night (`TimeManager`).
- **The Ledger**: Immutable prayer logging via SHA-256 hashing (`LedgerManager`).
- **The Prism**: Accessibility tools for contrast, dyslexia, and font scaling (`AccessibilityManager`).

### 🚀 Hidden Features
- **God Mode**: Enter the Konami Code (`↑↑↓↓←→←→BA`) to access the Admin Dashboard.
- **The Centurion**: Run `triggerCenturion()` in the console to witness the 100th-step Easter Egg.

### 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3 (Glassmorphism, CSS Variables), Vanilla JS (ES6+ Modules).
- **Storage**: `localStorage` for privacy-first data persistence.
- **PWA**: `manifest.json` + `service-worker.js` for "Add to Home Screen" capability.
- **Performance**: Lazy loading, critical CSS, and resource hinting.

### 📱 Quick Start
1. **Open** `index.html` in any modern browser.
2. **Install**: Click "Add to Home Screen" on mobile or the Install icon in Chrome desktop.
3. **Enjoy**: The app works offline after the first visit.

### 📁 Structure
- `script.js`: The "Monolith" containing all 15+ Manager classes.
- `styles.css` / `theme.css`: The visual soul of the application.
- `assets/`: Audio and visual resources.
